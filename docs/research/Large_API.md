# Handling High Throughput APIs

At the beginning, the goal was to build a system capable of handling a large number of requests—up to **1 million requests per second (High Throughput APIs)**.

After researching and watching several videos, the following approaches were identified:

1. **Caching**
2. **Asynchronous Processing**
3. **Containerization using Workers**
4. **Distributing requests across multiple application servers**
5. **Load Balancing**
6. **Using faster protocols such as HTTP/2 or HTTP/3**
7. **Using a fast method to fetch data from the database**
